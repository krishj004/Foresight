Foresight

Event in, probability + timeline + sourced report out. A forecasting engine built on a Halawi-style retrieval pipeline, a multi-model ensemble, an order-preserving calibration layer, and a resolution loop that keeps a Brier-scored track record.

Open interactive architecture → View source 中文架构图

Start

# one-command engine install (prebuilt binary, no Python needed)
npm i -g foresight-agent

# predict an event
foresight-engine "Will the Fed cut rates in September?" --closes 2026-09-17

# or run from source
git clone https://github.com/krishj004/Foresight.git
cd Foresight && uv sync && uv run pytest

How it works

  • Pipeline — Halawi five-step: search-term generation → retrieval → relevance filtering → summarization → base-rate + prediction.
  • Ensemble — 5–12 models, median aggregation, then order-preserving calibration.
  • Resolution loop — dual-source market comparison, LLM resolver with evidence and a confidence guardrail, manual fallback; Brier scores and calibration curves update as questions resolve.
  • Sourcing — Polymarket Gamma pipeline plus an autonomous topic-selection engine over 20 RSS sources.
